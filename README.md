# حكاوي كوين — Hikawi Coin

تطبيق واجهات عربي باتجاه RTL، بهوية ملكية داكنة تجمع الذهبي والبنفسجي، ومهيأ للموبايل وسطح المكتب.

## المرحلة الأولى: أساس React + TypeScript
- React 19 وTypeScript بوضع strict.
- Vite لتشغيل التطوير وبناء نسخة الإنتاج.
- تقسيم الواجهات إلى صفحات ومكونات واضحة داخل تطبيق React.
- الاحتفاظ بنظام التصميم الحالي في `styles.css`.
- فحوصات الأنواع والبناء عبر `npm run typecheck` و`npm run build`.

## التشغيل محليًا
يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## الصفحات
الرئيسية، الغرف الصوتية، البث المباشر، اللحظات، الرسائل، الألعاب، الملف الشخصي، المحفظة، المتجر الملكي، الإعدادات، ومركز المساعدة.

## حدود هذه المرحلة
المحتوى والأرصدة والأعضاء المعروضون بيانات تجريبية. لم يتم ربط المصادقة أو قاعدة البيانات أو الصوت المباشر أو الفيديو أو المدفوعات أو إرسال الهدايا الفعلي. لن يتم اعتبار أي إجراء تجريبي معاملة حقيقية.

ملف `app.js` القديم محفوظ كسجل للواجهة الأولية، لكنه لم يعد محمّلًا في تطبيق React.
