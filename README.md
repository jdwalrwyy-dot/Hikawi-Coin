# حكاوي كوين — Hikawi Coin

تطبيق واجهات عربي باتجاه RTL، بهوية ملكية داكنة تجمع الذهبي والبنفسجي، ومهيأ للموبايل وسطح المكتب.

## المرحلة الأولى: أساس React + TypeScript
- React 19 وTypeScript بوضع strict.
- Vite لتشغيل التطوير وبناء نسخة الإنتاج.
- تقسيم الواجهات إلى صفحات ومكونات واضحة داخل تطبيق React.
- فحوصات الأنواع والبناء عبر `npm run typecheck` و`npm run build`.

## المرحلة الثانية: أساس الحسابات والحماية
- تسجيل الدخول باستخدام Google أو رقم الهاتف ورمز SMS عبر Firebase Authentication.
- إنشاء/تحديث ملف المستخدم في Firestore من بيانات مزود الدخول، من غير تخزين كلمات مرور.
- قواعد Firestore تقصر بيانات المحادثات على طرفي صداقة موثقة.
- سجلات الصداقة نفسها لا يستطيع تطبيق العميل إنشاءها أو تعديلها؛ يلزم خادم موثوق ينشئها بعد قبول طلب الصداقة.
- أرصدة المحافظ وسجل المعاملات للقراءة المصرح بها فقط، والكتابة ممنوعة من تطبيق العميل.
- انسخ `.env.example` إلى `.env.local` وأدخل إعدادات Firebase قبل تجربة تسجيل الدخول.

## إعداد Firebase المطلوب
1. أنشئ أو اختر مشروع Firebase المخصص لحكاوي كوين.
2. فعّل Authentication providers: Google وPhone.
3. أنشئ قاعدة Firestore وانشر `firestore.rules` بعد مراجعتها.
4. أضف دومين المعاينة والنشر إلى Authentication > Settings > Authorized domains.
5. أضف قيم إعداد تطبيق الويب إلى متغيرات البيئة الموضحة في `.env.example`.

هذا المستودع لا يحتوي على بيانات مشروع Firebase أو مفاتيح سرية، ولم يتم الادعاء بربط مشروع خارجي دون صلاحية وبيانات مؤكدة.

## التشغيل محليًا
يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## حدود المرحلة
المصادقة وتهيئة ملف المستخدم جاهزان برمجيًا بعد توفير إعدادات Firebase. إنشاء سجلات الصداقة بعد قبول الطلب، وخدمات الرسائل الفعلية، وقراءة الغرف الحية، والصوت والفيديو والمدفوعات، تحتاج خدمات خادم وربطًا فعليًا واختبارات منفصلة. لا تستخدم الأرصدة التجريبية كأرصدة مالية.
