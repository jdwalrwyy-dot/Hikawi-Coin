# حكاوي كوين — Hikawi Coin

واجهة عربية RTL بتصميم ملكي داكن يجمع الذهب والبنفسجي، ومهيأة للموبايل وسطح المكتب.

## الملفات
- `index.html`: هيكل الواجهات والتنقل.
- `styles.css`: نظام التصميم والاستجابة للشاشات.
- `app.js`: تفاعلات المعاينة والتنقل والنوافذ.

## الشاشات الموجودة في التصميم
الرئيسية، الغرف الصوتية، البث المباشر، اللحظات، الرسائل، الألعاب، الملف الشخصي، المحفظة، المتجر الملكي، الإعدادات، ومركز المساعدة.

## الحالة التقنية
هذه مرحلة واجهات وتجربة استخدام أولية (Front-end prototype). الأرقام والمحتوى المعروض أمثلة تصميمية وليست بيانات مستخدمين حقيقية. لم يتم بعد ربط Firebase أو المصادقة أو Agora أو البث أو المدفوعات أو نظام الهدايا الفعلي.

يمكن فتح `index.html` مباشرة لمعاينة التصميم.
