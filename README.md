# حكاوي كوين — Hikawi Coin

تطبيق واجهات عربي باتجاه RTL، بهوية ملكية داكنة تجمع الذهبي والبنفسجي، ومهيأ للموبايل وسطح المكتب.

## المرحلة الأولى: أساس React + TypeScript
- React 19 وTypeScript بوضع strict.
- Vite لتشغيل التطوير وبناء نسخة الإنتاج.
- تقسيم الواجهات إلى صفحات ومكونات واضحة داخل تطبيق React.
- الاحتفاظ بنظام التصميم الحالي في `styles.css`.
- فحوصات الأنواع والبناء عبر `npm run typecheck` و`npm run build`.

## التشغيل محليًا
يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## الصفحات
الرئيسية، الغرف الصوتية، البث المباشر، اللحظات، الرسائل، الألعاب، الملف الشخصي، المحفظة، المتجر الملكي، الإعدادات، ومركز المساعدة.

## حدود هذه المرحلة
المحتوى والأرصدة والأعضاء المعروضون بيانات تجريبية. لم يتم ربط المصادقة أو قاعدة البيانات أو الصوت المباشر أو الفيديو أو المدفوعات أو إرسال الهدايا الفعلي. لن يتم اعتبار أي إجراء تجريبي معاملة حقيقية.

ملف `app.js` القديم محفوظ كسجل للواجهة الأولية، لكنه لم يعد محمّلًا في تطبيق React.

## المرحلة الثانية: أساس الحسابات
- تسجيل الدخول باستخدام Google أو رقم الهاتف ورمز SMS عبر Firebase Authentication.
- تهيئة ملفات المستخدمين في Firestore دون تخزين كلمات مرور أو أسرار داخل المستندات.
- قواعد Firestore تمنع تعديل الأرصدة والمعاملات من تطبيق العميل، وتقصر الرسائل على أطراف المحادثة.
- انسخ `.env.example` إلى `.env.local` وأدخل إعدادات مشروع Firebase الخاص بالتطبيق قبل تجربة تسجيل الدخول.
- أضف نطاق المعاينة/النشر إلى Authorized domains في Firebase Authentication، وفعّل Google وPhone من مزودي تسجيل الدخول.
- راجع `firestore.rules` وانشرها إلى مشروع Firebase بعد مراجعتها. لا توجد بيانات مشروع أو مفاتيح سرية مضمّنة في المستودع.

### إعداد Firebase
القيم المطلوبة موضحة في `.env.example`. هذا المستودع يجهّز التكامل البرمجي والقواعد، لكنه لا ينشئ مشروع Firebase ولا يفعّل مزودي الدخول نيابةً عن مالك المشروع.
