# حكاوي كوين | Hikawi Coin

**حكاوي كوين** منصة اجتماعية عربية للغرف الصوتية والبث المباشر، تجمع الأصدقاء وصنّاع المحتوى في مساحة واحدة للتواصل والترفيه والفعاليات.

## وصف المنتج

تجربة عربية كاملة باتجاه RTL، بهوية ملكية فاخرة، وواجهة متجاوبة للهواتف والأجهزة اللوحية وسطح المكتب. تجمع المنصة بين:

- **الرئيسية:** شريط إعلانات يديره المالك، الغرف الأكثر رواجًا، غرفة الإدارة المثبتة، قائمة الغرف العامة، البحث وإنشاء الغرف.
- **الغرف الصوتية:** حتى 27 مقعد مايك، عرض الأعضاء وحالات المايك، مشرفو الغرف، كتم وطرد وحظر، قفل وفتح المايكات، وتغيير صورة وخلفية الغرفة ونقل الملكية.
- **البث المباشر:** بث صوت وصورة، اكتشاف البثوث، دخول المشاهدين، تفاعل مباشر، وجودة متكيفة مع سرعة الاتصال وإعادة الاتصال عند الانقطاع.
- **الهدايا والمحفظة:** هدايا عادية وفاخرة متحركة، ماسات وكونز، سجل إرسال واستقبال الهدايا والمعاملات، مع حماية أرصدة الخادم ومنع تعديلها من العميل.
- **الألعاب والفعاليات:** لودو، ورق وكوتشينة، ألعاب أسئلة وتحديات، مسابقات أسبوعية، حفلات الغرف، ولوحات المتصدرين.
- **اللحظات:** نشر الصور والفيديو والنصوص، الإعجاب والتعليق والمشاركة.
- **الرسائل والأصدقاء:** رسائل خاصة للأصدقاء، طلبات صداقة، متابعون ومتابَعون، الأصدقاء المتصلون، والبحث عن الأشخاص والغرف والوكالات والمضيفين.
- **الملف الشخصي والمتجر:** تعديل الملف الشخصي، الإطارات والألقاب والزخارف، ومتجر الهدايا والدخول المميز.
- **الخصوصية والأمان:** التحكم في الظهور وآخر ظهور والرسائل وطلبات الصداقة والحظر، وسجل نشاط المستخدم.
- **الدعم:** تذاكر شكاوى مرقمة، متابعة الحالة، إرفاق الأدلة، وتقييم الدعم.
- **إدارة المالك:** صلاحيات مالك شاملة للحسابين المعتمدين، وإدارة المستخدمين والغرف والوكالات والمضيفين والأرصدة والإعلانات والفعاليات والإشعارات، مع سجل تدقيق للعمليات الحساسة.
- **التشغيل والموثوقية:** نسخ احتياطية واستعادة، مراقبة الأعطال، تنبيهات توقف الخدمات، ولوحة تحليلات للمالك.
- **الإعدادات:** الوضع الملكي الداكن (أسود وذهبي) والوضع الفاتح (أبيض وذهبي)، مع اختيار المستخدم.

## التنقل الرئيسي

الرئيسية · مباشر · ألعاب · لحظات · رسائل · حسابي

## التقنية الحالية في المستودع

- React 19 + TypeScript بوضع strict.
- Vite 6 لبناء وتشغيل واجهة الويب.
- Firebase Authentication (Google ورقم الهاتف) وCloud Firestore.
- قواعد Firestore تمنع الكتابة المباشرة من العميل إلى أرصدة المحافظ وسجل المعاملات.
- واجهة RTL وخط Cairo، وتصميم متجاوب.

## ما يعمل في النسخة الحالية

- تسجيل الدخول الحقيقي باستخدام Google Popup أو رقم الهاتف مع رمز SMS عبر Firebase Authentication، بشرط تفعيل المزوّدين في Firebase وإضافة نطاقات Vercel إلى Authorized domains.
- إنشاء ملف المستخدم بعد تسجيل الدخول وحفظ بياناته الأساسية في Firestore.
- عرض الغرف العامة من Firestore وإنشاء غرفة والانضمام إليها كسجل عضوية. هذا لا يشغّل الصوت بحد ذاته.
- نشر اللحظات النصية أو صور وفيديوهات عبر Firebase Storage، مع الإعجاب والتعليقات في Firestore بعد نشر القواعد.
- صفحات رئيسية للأقسام: الرئيسية، مباشر، لحظات، ألعاب، رسائل، حسابي.

## ما يحتاج ربطًا خارجيًا قبل اعتباره مكتملًا

البث المرئي المباشر، نقل الصوت في الغرف، مقاعد المايك الفعلية، مكالمات الصوت والفيديو، المحادثات الفورية الخاصة، الإشعارات، الهدايا ومدفوعاتها، الألعاب الجماعية، الإعلانات الممولة، وأدوات الإدارة الكاملة تحتاج خدمات خادم ومزود RTC وصلاحيات آمنة واختبارات تشغيل. هذه الشاشات لا تعرض وظائف وهمية على أنها متصلة.

## نشر قواعد Firebase

بعد مراجعة القواعد، انشر `firestore.rules` و`storage.rules` على مشروع Firebase الحالي. ملف `firebase.json` يحدد مسارات القواعد. فعّل Google وPhone في Firebase Authentication، وأضف نطاق معاينة Vercel ونطاق الإنتاج إلى Authorized domains. لا تنشر قواعد أو تغييرات على قاعدة البيانات الحالية دون أخذ نسخة احتياطية ومراجعتها.

## تشغيل المشروع

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## إعداد Firebase

1. أضف قيم تطبيق Firebase إلى متغيرات البيئة الموضحة في `.env.example`.
2. فعّل Google وPhone في Firebase Authentication.
3. أنشئ Firestore وانشر `firestore.rules` بعد مراجعتها.
4. أضف نطاقات المعاينة والإنتاج إلى Authorized domains.
5. لا تضع كلمات مرور أو مفاتيح خادم أو أسرار إدارية في كود الواجهة.

## مبادئ حماية أساسية

- لا تخزّن كلمات مرور المستخدمين في Firestore.
- لا تسمح للعميل بتعديل أرصدة الماسات أو الكونز أو سجلات المعاملات.
- كل صلاحية مالك أو مشرف على مستوى التطبيق يجب التحقق منها على الخادم، لا بمجرد إخفاء زر في الواجهة.
- سجّل عمليات الإدارة الحساسة في سجل تدقيق.
- حافظ على قاعدة البيانات الحالية وبيانات المستخدمين عند أي تحديث، ولا تنفذ ترحيلًا أو حذفًا دون خطة معتمدة ونسخة احتياطية.
